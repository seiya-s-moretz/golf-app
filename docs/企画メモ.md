## 1. 既存資料からの現状把握（サマリ）

- **コンセプト（既存）**: ゴルフプレイヤー同士のマッチング・ラウンド募集・掲示板投稿・プロフィール管理を行うコミュニティアプリ
- **画面構成**: ホーム（ラウンド募集一覧）／おすすめユーザ／掲示板／マイページ の4タブ構成
- **コア機能**:
  - ラウンド募集の作成・一覧・参加申請（ホーム）
  - スコア差・住居エリア・目的の一致度に基づくレコメンド（おすすめユーザ）
    - スコア差±10以内: 40点／住居エリア一致: 40点／目的一致: 20点 → 60点以上で推薦
  - ラウンド結果を共有する掲示板（テキスト投稿のみ、現状は画像等の言及なし）
  - プロフィール（性別・年齢・住まい・アベレージスコア・目的・自己紹介）
- **「目的」の選択肢**: 「わいわい」「ガチ」「レクチャー求」の3種類のみ。恋愛・婚活を示唆する項目・文言は既存資料のどこにも存在しない。
- **技術スタック（参考情報。変更提案ではない）**: Android Kotlin, MVVM + Container + Hilt + Clean Architecture。ディレクトリ構成・データモデル（User/RoundEvent/BoardPost）・API・UIStateまで既に具体化済み。企画としては、この技術方針を概ね踏襲できる前提でアイデアを検討した。

## 2. 競合分析：スイングサプリ

事前情報では「スイング診断・レッスン系アプリ」とされていたが、公式サイト（swingsapuri.com）を確認したところ、
**実態は本アプリと非常に近いポジションの「20〜30代限定ゴルフコミュニティ・マッチングアプリ」**であることが判明した。
この前提修正は差別化戦略上重要なため、以下に実態を整理する。

### スイングサプリの実態

| 項目 | 内容 |
|---|---|
| コンセプト | 「同世代で行くゴルフ 超楽しいっ！」同世代の友人関係構築支援 |
| ターゲット | 20代・30代限定（30〜40代向け別コミュニティも存在）。初心者〜中級者中心 |
| 対応エリア | 関東＋山梨・静岡に限定 |
| 主要機能 | イベント検索・参加マッチング、参加者募集、ユーザー間チャット、プロフィール（腕前・評価） |
| 料金 | 月額無料、ラウンド参加ごとに手数料500円（友達登録済みユーザー主催のイベントは無料） |
| 運営形態 | 運営/主催者側がイベントを立てる形が中心とみられる（コミュニティ運営主導色が強い） |
| 恋愛・婚活要素 | **明確に禁止**（「ゴルコン」等、男女の出会い目的の利用・イベント開催は規約で禁止） |
| 実績 | 参加者の95%が「ゴルフ仲間が見つかった」と回答（公式訴求） |

### 本アプリとの比較・差別化の方向性

| 観点 | スイングサプリ | 本アプリ（案） |
|---|---|---|
| マッチングの単位 | イベント単位（集団参加） | 個人対個人（1対1のレコメンド）＋ラウンド募集（少人数〜） |
| マッチングロジック | 明示的な推薦アルゴリズムは不明（イベント参加ベース） | スコア差・エリア・目的の加点方式による明示的なレコメンドロジックが既に設計済み。「なぜこの人がおすすめされたか」が説明可能な点が強み |
| 対応エリア | 関東＋山梨・静岡限定 | エリア限定なし（全国展開できる余地。ただしローカル性の高いサービスであることは要考慮） |
| コミュニティ/SNS要素 | チャット中心 | 掲示板（ラウンド結果投稿）による記録・共有のSNS的要素 |
| 「目的」の可視化 | 明示的な目的タグは不明 | 「わいわい／ガチ／レクチャー求」を最初から明示し、ニーズドリブンなマッチングが可能 |
| 恋愛・婚活 | 明確に禁止 | **未定（要確認、下記参照）** |

**示唆**: 単純な「ゴルフ仲間探し」領域ではスイングサプリと機能が重複しており、後発として同じ土俵で戦うと厳しい。
差別化の軸になり得るのは、(1) 個人単位の明示的レコメンドロジック、(2) エリア非限定、(3) 目的タグによるニーズの解像度、(4) 掲示板を活かした記録・継続利用の設計。

## 3. コンセプト案（発散）

以下、否定せずまず広げる形で複数案を提示する。実現可能性や独自性の評価はA〜Eそれぞれの末尾に付記。

### 案A: 「ちょうどいいレベルで回れる、スコアマッチのゴルフ仲間探し」
アベレージスコア差でマッチングする点を前面訴求。「初心者だから気を遣う」「うまい人に混ざるのが怖い」という不安を解消する。
→ 既存の推薦ロジックとの親和性が最も高く、実現可能性は高い。ただしスコア自己申告制の信頼性が課題になりうる。

### 案B: 「一人でも気軽に、ラウンド募集掲示板」
一人参加を前提にしたラウンド募集UXを訴求（スイングサプリと近い訴求だが、個人発信の募集を主軸にする点で差別化）。
→ 実現可能性は高いが、スイングサプリと差別化しにくく独自性は弱め。

### 案C: 「ゴルフ×記録SNS、今日のラウンドを共有しよう」
掲示板を「ラウンド結果の記録・共有フィード」として強化し、Instagram的な継続利用導線を作る。写真投稿やスコア記録との連携など。
→ 既存設計は投稿がテキストのみのため、画像投稿などは追加検討が必要（技術要件はArchitectAgent/PM領域）。独自性・継続利用の観点で有望。

### 案D: 「全国どこでも使える、エリア非限定のゴルフマッチング」
スイングサプリが関東+山梨静岡限定である点を突き、全国（特に地方都市）をターゲットにする。
→ 実現可能性は高いが、初期ユーザー数が少ないと「近くに人がいない」体験になりやすく、地域を絞ったスモールスタート戦略との両立を検討する必要がある。

### 案E（要確認・リスク明示）: 「出会いも歓迎の、大人のゴルフコミュニティ」
スイングサプリが明確に禁止している「異性との出会い」要素を、あえて許容/訴求する案。20〜30代の独身層には一定の需要が見込める領域。
→ 独自性は高いが、(1) 既存資料に方針の手がかりが一切ない、(2) 安全性・治安面のリスク（トラブル、規約設計、本人確認等の負荷増）、(3) 「健全なスポーツコミュニティ」を求める層の離脱リスク、を伴う。
**この案を採用するか、案A〜Dのような非恋愛軸で行くかは、次工程に進む前にユーザー自身の意思決定が必要な最重要論点**（詳細は5章）。

### 案の組み合わせについて
A・C・Dは互いに排他的ではなく、組み合わせ可能（例：「スコアマッチ×記録SNS」を軸にしつつ全国展開を視野に入れる）。
Eは他の案と独立した論点（サービスの性格を左右するため単独で意思決定すべき）。

## 4. 想定ユーザー像（ペルソナ、たたき台）

### ペルソナ1: 「一人でも回りたい初心者」（20代後半・会社員・性別問わず）
ゴルフを始めて1〜2年、道具は揃えたが一緒に行く人がいない。誘われるのを待つのではなく自分から探したい。
うまい人に混ざると気後れするため、近いレベルの人を探せる安心感を重視。

### ペルソナ2: 「転勤・転職で人間関係がリセットされた30代」
新しい土地でゴルフ仲間を一から作りたい。エリアマッチング機能への期待が高い層。

### ペルソナ3: 「本気で上達したい中級〜上級者」（目的：ガチ）
なあなあの付き合いゴルフではなく、同じ熱量で真剣に回れる相手を求めている。

### ペルソナ4: 「教えたい人／教わりたい人」（目的：レクチャー求）
経験者は自分の知識を活かしたい、初心者は独学に限界を感じている。両者をつなぐニーズ。

### ペルソナ5（要確認）: 「ゴルフをきっかけに出会いも探したい層」
案Eを採用する場合に想定されるペルソナ。既存資料には根拠がなく、方針次第で追加・削除する。

## 5. 未検証の前提・リスク・要確認事項

以下は企画段階で判明した、ユーザーへの確認が必要な事項。PMへの引き継ぎ前に方向性を固めることを推奨。

1. **【最重要】恋愛・婚活要素を含めるか否か**
   既存の5設計資料には、恋愛・婚活を示唆する項目・文言が一切存在しない（「目的」は「わいわい／ガチ／レクチャー求」の3種のみ）。
   一方で競合スイングサプリはこれを明確に禁止しており、差別化の余地がある領域でもある。
   サービスの性格（健全なスポーツコミュニティ路線か、出会いも許容する路線か）を左右する最重要論点のため、要件定義前にユーザーの意思決定を仰ぎたい。

2. **展開エリアの方針**
   スイングサプリは関東＋山梨・静岡に限定してコミュニティ密度を担保している。本アプリを全国展開する場合、初期のマッチング成立率（近くに該当ユーザーがいない問題）をどう担保するか要検討。地域を絞ったスモールスタートも選択肢。

3. **スコアの信頼性**
   アベレージスコアは自己申告制と推測される（既存資料にスコア証明の仕組みの記載なし）。サバ読み対策（スコア入力の任意/必須、実績連携等）を要件定義段階で検討する余地がある。

4. **掲示板投稿の形式**
   既存設計では投稿はテキストのみ（画像投稿の記載なし）。SNS的な継続利用を狙う場合、画像投稿やいいね機能等の拡張余地があるが、これは技術要件・優先順位の話としてPM/Architectと詰める。

5. **マネタイズ方針**
   既存資料にはマネタイズ（課金、手数料等）の記載が一切ない。スイングサプリは参加ごと500円のチケット制。本アプリの収益モデルは未検討であり、企画段階では触れていない。要件定義時に別途検討が必要。

6. **安全性・本人確認**
   個人間マッチングかつオフラインで実際に会う（ラウンドする）性質上、なりすまし対策・本人確認・通報機能等の要否は、案Eを採用する場合は特に重要度が増す。
